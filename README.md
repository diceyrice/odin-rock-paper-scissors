# odin-rock-paper-scissors
A basic game of rock-paper-scissors using HTML, CSS, and JS.

## Features
* Random selection from the web page against the user's choice
* Loops to continue rounds of rock-paper-scissors until either the user or the computer reaches 5 wins
* Reset button to replay after 5 wins from either side
